# Milestone 4: v0.1 polish (gallery, before/after README, API docs, one-command CS1)

## What was built

- **One-command reproduction.**
  - After `pip install -e .`, running `python case_studies/cs1_sciplex_hdac.py` does everything: downloads sci-Plex3 from GEO (checksum-verified), builds the per-well cache on first use, fetches the Hallmark gene sets, runs the five plots and writes the report.
  - The README has a dedicated section, and states the 3.2 GB first-run download.
- **Gallery** (`docs/gallery.md`, generated by `docs/make_gallery.py`): every plot next to its classic counterpart, with the generated caption and a short "what changes" list.
  - The five sci-Plex figures come from CS1.
  - Plate Atlas is shown on **synthetic** test plates; GDSC figures stay local (licence).
- **README:** a before/after table (Compass vs PCA, Dose Paths vs PCA by dose, Effect Ladder vs volcano), install, one-command CS1, and a Quick look whose snippets were run as written.
- **API reference** (`docs/api.md`, generated by `docs/make_api.py` from docstrings; no new dependencies). `tests/test_docs.py` fails when the file is out of date, and it caught exactly that once during this milestone.
- **User-study kit** (`case_studies/user_study.py`, protocol in `docs/user_study.md`), covering HANDOVER §10:
  - 9 items on 5 classic/tincture figure pairs, with answers computed from CS1's `results.json`;
  - each item flagged by whether the classic figure can answer it in principle;
  - counterbalanced assignments for 10 participants (each item shown 5× in each version), a response template and a first-pass scorer.
- **Fairer classic fallbacks**, so they are the best conventional versions rather than straw men:
  - the Compass PCA now colours reference classes;
  - the PCA by dose marks and labels each compound.
- **Tests:** 270 passing (plus 7 opt-in real-data tests), including the API-docs staleness test, the gene-set fetch without decoupler, and user-study answer matching.

## Acceptance: "a new user can reproduce CS1 from the README in one command"

**Verified** on a fresh `git clone`, a new Python 3.12 environment with `pip install -e .` only (decoupler not installed), and an empty data cache. To avoid re-downloading the same 3.2 GB, the raw GEO files were linked in; their checksums are still verified on load. Everything else ran from scratch: building the per-well cache, downloading the gene sets and the analysis.

- Total time: **311 s** (the cache build was about 3 min of that), exit 0.
- Report: all three ground-truth checks ✅, with results identical to the main checkout's run.
- The GEO download itself was verified in M1 (checksums in `docs/data_status.md`), and the GEO host answered 200 during M4.

## What failed or changed along the way

1. **The first fresh-user run failed.** Fetching gene sets required decoupler, which is only in the 600 MB `[omics]` extra, so a core install could not run CS1. Hallmark is now read straight from OmniPath's static table with the same processing as decoupler. I checked: identical 7,318 set–gene pairs. PROGENy still needs decoupler.
2. **`load_sciplex3` refused to build its cache unless asked**, so CS1 now passes `build=True`.
3. **A committed docs image contained GDSC data.** The M2 restyle before/after image showed a GDSC plate map and per-plate QC, which conflicts with the recorded practice that derived GDSC data stay local. It is now cropped to its sci-Plex half and logged in `docs/data_status.md`. At your request the branch history was rewritten so that no commit contains the GDSC version (12 commits, force-pushed; the final tree is unchanged).
4. **The Compass methods paragraph was stale.** It still described the radius as "the norm of the shrunk signature" after the noise correction; rewritten.
5. **CS1 Fingerprint check (from M3).** Re-run once with the pharmacological HDAC group you chose, defined before running: 0.83 within vs 0.59 between, p = 0.0005, all checks pass. Recorded in `docs/milestone_3.md`.

## Decisions taken

- **Gallery and README use only sci-Plex (GEO) or synthetic figures,** given the GDSC terms.
- **The user study withholds captions,** to compare the figures themselves; captions state many answers outright. A with-captions arm is suggested as a follow-up.
- **API docs are generated Markdown, not Sphinx/MkDocs.** That keeps dependencies at zero; a site generator can be added later if you want a hosted site.
